# 三國志III × 日語 N5 霸業篇

純前端、零外部素材的《三國志III》風格回合制歷史策略遊戲，將 **JLPT N5 日語介面詞彙教學** 直接融入策略遊玩流程。

## 功能特色

- **純前端、零外部素材**：僅使用原生 HTML / CSS / JavaScript、HTML5 Canvas 地圖、SVG 程式繪製武將頭像、Web Audio API 復古音效與瀏覽器 `speechSynthesis` 日語發音。
- **劇本與君主選擇**：收錄 `189年 董卓專橫`、`194年 群雄割據`、`207年 三顧茅廬` 三大劇本，可扮演曹操、劉備、孫堅／孫策／孫權、董卓、呂布、袁紹、馬騰、劉表、劉璋等勢力。
- **內政與外交系統**：開墾、商業、治水、補修城牆、買糧、施捨民心、徵兵、訓練、探索在野武將、登用、外交同盟、偵察與物資輸送，並包含季稅、秋收與本機 `localStorage` 存檔。
- **回合制戰術野戰／攻城**：10×7 地形格網（平地、森林、山地、河川、城門、本陣）、天氣系統（晴／強風／雨）、火計與三回合「一騎討ち（單挑）」對決。
- **日語 N5 學習整合**：
  - **介面假名讀音**：所有介面資源、指令、方角、地形與季節皆標註日文漢字 `<ruby>` 振假名，點擊可查看單字卡與聽取發音。
  - **今月之言葉**：每月自動輪換一個 N5 核心單字與三國情境例句。
  - **私塾測驗**：每月可進行 3 題 N5 測驗（含詞義、中翻日與漢字選讀音），答對即贈送城池軍資金與內政效率加成。

## 遊玩方式

直接用瀏覽器開啟 `index.html` 即可開始遊戲。
